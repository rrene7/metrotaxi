# Cambios Metro Taxi v0.8 (20-11-2026)

**Base:** v0.6 (cuentas de pasajero, QR, ficha taxista, central y conductor).

**Nuevo:** expediente vehículo completo, turnos, GPS en pantalla abierta, ubicación reciente visible solo al pasajero de un servicio aceptado, cancelación, caducidad de ofertas, sugerencias de taxi próximo por distancia recta, despacho automático tras 120 segundos (administrador debe habilitarlo), historial anti-reofertas, cambio de contraseña y PWA instalables en entorno seguro.

**Pruebas:** 32 integraciones HTTP sobre base temporal, y validación sintáctica del JS. No se realizó instalación Android ni visualización real de GPS en dispositivos físicos.

**Limitaciones:** NO producción, NO APK firmada, NO URL pública, NO WhatsApp integrado; proveedor de mapas pendiente de revisión. Condiciones de privacidad, aprobación de fotografías y catálogo territorial pendientes para uso comercial.
